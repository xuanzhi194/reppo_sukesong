架构分层

硬件 BSP 层

  • LCD、EC06、RX8130、电池、RGB、蜂鸣器、WiFi、BLE、AI HTTP 客户端。
  • 主要目录：components/BSP。

系统服务层

  • NVS、SPIFFS、WiFi worker、NVS worker、LVGL port、SNTP/RTC 切换。
  • 主要目录：main、components/lv_port。

应用功能层

  • 主界面、Todo、番茄钟、专注、单词卡、AI 总结、设置、答案书。
  • 主要目录：components/ui_custom、main/app_ui.c。

外部工具层

  • AI 代理服务、网页烧录站、可复用 BSP 文档。
  • 主要目录：server/ai_proxy、web-flash、reusable_bsp。

核心功能清单

显示与输入

  • ST7789P3 8080-I8，横屏 320x170。
  • LVGL 8，双缓冲，DMA flush，100ms 超时保护。
  • EC06 旋钮映射 LVGL keypad，GPIO5 确认键。

时间与电源

  • RX8130 RTC，WiFi 在线时 SNTP 同步，离线读取 RTC。
  • 403450 800mAh 电池，ADC + TP4056 CHRG/STDBY 判断。
  • 电量使用 SOC 曲线、状态机和平滑策略。

学习与专注

  • Todo CSV、Done 归档、BLE 同步。
  • 番茄钟、秒表、任务绑定专注、等级累计。
  • 单词卡随机学习 30 个，错词复习队列。

AI 与连接

  • WiFi 配网、凭据保存、SNTP 管理。
  • NimBLE GATT，支持 JSON 分片和 notify。
  • AI 日/周总结通过 ECS Proxy 调 DeepSeek。

数据流

时间

flowchart LR
  WiFi[WiFi connected] --> SNTP[SNTP sync]
  SNTP --> SYS[System time]
  SYS --> RTC[Sync RX8130]
  RTC --> UI[LVGL time labels]
  OFF[WiFi offline] --> RTCREAD[Read RX8130]
  RTCREAD --> UI

Todo 与 AI

flowchart LR
  BLE[BLE JSON] --> TODO[/todo.csv/]
  TODO --> UI[Todo UI]
  UI --> FOCUS[Focus countdown]
  FOCUS --> DONE[/task_done.csv/]
  DONE --> PROMPT[Build prompt]
  PROMPT --> PROXY[ECS AI Proxy]
  PROXY --> DS[DeepSeek]
  DS --> RESULT[NVS AIData]
  RESULT --> AIUI[AI screen]

待确认与扩展边界

  • 当前 AI 功能是“固定数据总结”，不是完整代码 agent。若要自然语言生成任意固件，需要服务器侧代码生成、编译、日志反馈、固件产物管理和沙箱。
  • 当前 LVGL 未启用 GIF/PNG/BMP 解码。任意图片/GIF 显示需要资源生成/上传、转换压缩、存储、解码和屏幕适配链路。
  • CSV 适合受控数据，复杂自然语言任务文本建议升级为 JSON 或严格 CSV 转义。
  • BLE 配置启用角色较多，量产前可按真实角色收窄以节省内存。
  • 工程名和网页烧录 bin 名仍是 project-name，发布前建议统一为 Reppo。
